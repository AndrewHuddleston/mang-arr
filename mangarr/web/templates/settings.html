Sources
The sources installed in Suwayomi. Untick one to stop using it: it is neither searched nor downloaded from. Rate limiting is detected automatically: a source that starts refusing requests is paced (one chapter at a time, a pause between chapters) and loses close calls to other sources for {{ auto_days }} days.
A source whose image server refuses bursts (Comick) can be fetched page by page ("one by one"): each page is requested through Suwayomi a few seconds apart, then Suwayomi builds the chapter from its cache. That is slow (2-4 min a chapter), so such a source is used only for chapters no other source lists.
